# ADR 0002 — Recovered product and design authority

Date: 2026-09-23
Status: ACCEPTED

## Decision
The authoritative product is a mobile-first practical journey planner for Trinidad and Tobago, not a route-count atlas.

Latest recovered design decisions:
- working brand direction: lowercase “trinimaps”;
- Transit-first/default map mode plus Standard and Satellite;
- preserve real maxi band/color semantics;
- route highlight ends at rider alighting point;
- concise directions with evidence in one expandable area;
- formal stands/terminals and ordinary Places/landmarks are both searchable;
- mode choice may require/prefer that mode while allowing necessary connectors;
- honest “data gap / no verified route” is better than invented connectivity;
- field review creates evidence/proposals, never direct public edits.

## Superseded
Early README language that prioritized an atlas before journey planning is historical.
Any implementation/test requiring proximity corridor bridges is superseded.
Any service/direction/corridor conflation is superseded by docs/DOMAIN.md.
